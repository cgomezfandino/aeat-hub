# AEAT Hub · web

Interfaz Next.js del motor fiscal. Arranque, seguridad y arquitectura: [`../docs/web.md`](../docs/web.md).

```bash
pnpm install
AEAT_HUB_API_TOKEN_FILE=/ruta/datos/api-token pnpm dev   # http://127.0.0.1:3000
pnpm test        # formato de importes
pnpm typecheck   # contra los tipos del OpenAPI (pnpm api:tipos para regenerarlos)
```
